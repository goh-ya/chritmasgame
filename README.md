# Christmas Gift Exchange
聖誕交換禮物為主題的互動式網頁，透過角色動畫與禮物交換機制，讓交換禮物的遊戲過程更加有趣！

## 專案介紹
以互動式網頁呈現聖誕交換禮物遊戲，玩家依照指定順序選擇或搶奪禮物，透過動畫呈現禮物的移動與歸屬變化。

## 主要功能
- 互動式角色與禮物選擇
- 禮物搶奪與交換機制
- 禮物鎖定與狀態變化
- 動態呈現遊戲流程
- 響應式網頁設計（RWD）

## 如何使用
1. 開啟網站
2. 點擊「開始遊戲」
3. 依照畫面提示進行禮物選擇與搶奪
4. 完成所有玩家的交換流程

此專案為聖誕節團隊活動所製作的互動式網頁，主要用於活動展示與遊戲體驗。
